# 04 — Statistical Quality Analysis

## Goal
Turn inspection data into decisions: sample size, yield, measurement confidence, process stability and disposition.

## Included analysis themes
- AQL / ANSI Z1.4-style sampling logic
- First-pass and incoming yield
- Pareto failure analysis
- GR&R / measurement-system evaluation
- Process capability and trend analysis
- Risk-based test sampling

## Example portfolio dataset
The `python/` folder is reserved for fully synthetic data so the analytical methods can be demonstrated without exposing proprietary company data.

## Example engineering question
> When a large lot has a known high-risk defect mode, how should test coverage be balanced between statistical sampling, risk severity and the consequences of an escape?
